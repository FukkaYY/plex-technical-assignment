# インターン生一覧

## 目的

企業担当者が登録済み学生の概要を比較し、詳細確認する候補を選べるようにする。

## 優先度・区分

- 優先度: P0
- 設計判断: 認証済み企業だけが閲覧できる。
- 設計判断: P0は新着順、1ページ20件とし、検索・絞り込みはP1にする。

## 表示項目

- 氏名
- 学校名
- 卒業予定年
- 希望職種
- スキルの一部
- 自己紹介の抜粋
- 登録日時

メールアドレスなどのログイン情報は返さない。

## API

`GET /api/v1/students?page=1`

- 成功: `200 OK`
- 未ログイン: `401 Unauthorized`
- 学生ロール: `403 Forbidden`
- 並び順: `created_at DESC, id DESC`
- ページサイズ: 20件固定
- レスポンスにページ番号、総件数、総ページ数を含める。

## 画面状態

- 読み込み中
- 一覧表示
- 登録学生が0件の空状態
- APIエラー
- 前後ページへの移動

## 受け入れ条件

- 認証済み企業が学生を新着順で閲覧できる。
- 20件単位でページ分割される。
- 学生カードから学生詳細へ移動できる。
- APIレスポンスに学生のメールアドレスが含まれない。
- 未ログインまたは学生ロールでは取得できない。
