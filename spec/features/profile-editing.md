# 学生プロフィール編集

## 目的

登録済みの学生が、企業へ公開される自分のプロフィール情報を最新の状態に更新できるようにする。

## 優先度・区分

- 優先度: P1
- 区分: 設計判断
- 対象: 認証済みの学生本人

## 編集項目

- 氏名
- 学校名
- 卒業予定年
- 希望職種
- スキル
- 自己紹介

メールアドレス、パスワード、roleはプロフィール編集の対象に含めない。入力検証と正規化は学生登録時と同じ規則を使う。

## API

`PATCH /api/v1/student_profile`

リクエスト:

```json
{
  "student_profile": {
    "name": "山田 太郎",
    "school_name": "プレックス大学",
    "graduation_year": 2028,
    "desired_role": "バックエンドエンジニア",
    "skills": ["Ruby", "Rails"],
    "self_introduction": "自己紹介"
  }
}
```

- 成功: `200 OK` と更新後の `data` を返す。
- 入力不正: `422 Unprocessable Entity`。保存済みプロフィールは変更しない。
- 未ログイン: `401 Unauthorized`。
- 企業ロール: `403 Forbidden`。
- CSRFトークンのない更新は拒否する。

## 画面

- 学生マイページから編集画面へ移動する。
- 編集画面は現在値を初期表示する。
- 更新成功後は学生マイページへ戻り、完了メッセージと更新後の概要を表示する。
- 入力不正時は項目ごとのエラーを表示し、入力内容を保持する。
- 未ログインは学生ログイン、企業ロールは学生一覧へ誘導する。

## 対象外

- メールアドレス・パスワード変更
- プロフィール画像
- プロフィール公開停止
- 管理者による編集

## 受け入れ条件

- 学生本人が編集対象の全項目を更新できる。
- 前後空白、空のスキル、重複スキルが登録時と同様に正規化される。
- 入力不正時に保存済みプロフィールが変更されない。
- 未ログインと企業ロールから更新できない。
- 更新後の学生マイページと企業向け学生一覧・詳細に変更が反映される。
