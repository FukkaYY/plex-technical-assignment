# 主要ユーザーフロー

## 学生登録・受信

```text
トップ
  → 学生登録
  → 入力検証
  → アカウント・プロフィール作成
  → 自動ログイン
  → 学生マイページ
  → 受信一覧
  → 受信詳細
```

## 企業によるスカウト

```text
企業ログイン
  → 資格情報と企業ロールを検証
  → 学生一覧
  → 学生詳細
  → メッセージ作成
  → 送信
  → 送信結果・会話履歴
```

学生一覧の実装前は、同じ `/students` に企業名、ログイン成功状態、ログアウト導線だけを表示する。

## 認証エラー

```text
保護画面へアクセス
  → APIが401を返す
  → ログイン画面へ誘導
  → ログイン成功後に適切な開始画面へ遷移
```

## 権限エラー

```text
異なるロールのAPIへアクセス
  → APIが403を返す
  → 権限エラー画面を表示
```
